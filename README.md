# StudyDock – Study Hall Management System

StudyDock is a web-based application designed to manage private study libraries and reading halls. It helps administrators efficiently manage students, seat allocations, subscription payments, and complaints while maintaining smooth communication between students and administrators.

The system simplifies daily operations of private libraries by digitizing seat management, payment tracking, and student activity monitoring.

---

## Key Features

### Student Module

* Student registration and login
* Unique seat allocation
* Monthly subscription tracking
* Upload payment screenshot (PhonePe/GPay/UPI)
* View payment history
* Submit complaints
* Profile management

### Admin Module

* Admin dashboard with analytics
* Student management
* Seat allocation and monitoring
* Payment verification
* Complaint management
* Announcement system

### Notification System

* Admin receives notifications when:

  * Students upload payment screenshots
  * Complaints are submitted
  * Seat change requests are made
  * New students register

### Payment Management

* Screenshot-based payment verification
* Monthly subscription tracking
* Overdue payment monitoring
